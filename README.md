# 🧍 Human Posture Detection

## 📌 Overview

This project is a real-time Human Posture Detection System developed using Artificial Intelligence and Computer Vision. It detects human body landmarks and estimates posture from images or webcam input.

---

## 🎯 Problem Statement

Human posture analysis is widely used in healthcare, fitness, sports analytics, rehabilitation, and human-computer interaction.

This project demonstrates how AI can detect and analyze body posture automatically.

---

## 🚀 Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Google Colab

---

## ✨ Features

- Real-time posture detection
- Human body landmark estimation
- Image processing
- Webcam support
- Computer Vision based analysis
